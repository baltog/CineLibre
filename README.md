# CinéLibre — V3

CinéLibre est une interface web de démonstration pour une plateforme de films et séries **gratuits et légaux**.

## V3
- Accueil type plateforme de streaming
- Catalogue films + séries
- Recherche instantanée
- Filtres par type et genre
- Tri par nouveauté, note ou titre
- Fiches détaillées
- Favoris enregistrés dans le navigateur
- Responsive mobile / ordinateur
- Rappel juridique intégré
- Aucun contenu réel protégé n'est fourni

## Mise en ligne GitHub Pages
1. Remplace les anciens `index.html`, `style.css` et `script.js` par ceux de cette version.
2. Garde `README.md` si tu veux.
3. Fais le commit.
4. GitHub Pages publiera automatiquement la nouvelle version si le dépôt utilise toujours `main` + `/(root)`.

GitHub indique qu'une publication depuis une branche peut utiliser la racine du dépôt comme source et que `index.html` doit être au niveau supérieur de cette source.

## Important
Les titres présents dans la démo sont fictifs. Pour ajouter des œuvres réelles, utilise uniquement des contenus du domaine public, des contenus sous licence autorisant la diffusion, ou des œuvres pour lesquelles tu possèdes les droits.
